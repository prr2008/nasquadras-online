    📄 Publicar do Google Docs

    O menu Nas Quadras → Enviar para o blog… dentro do Google Docs manda o texto, com intertítulos, links e fotos, direto para cá, como rascunho ou já publicado.

    1. Crie no Google Docs um documento chamado Modelo Nas Quadras.
    2. Nele, abra Extensões → Apps Script, apague o que houver e cole o script:
    3. Gere o código de conexão e cole-o entre as aspas da linha const CONEXAO = '';
    4. Salve (ícone de disquete), volte ao documento e recarregue a página. Toque em Nas Quadras → Enviar para o blog… e autorize o script (em “Google não verificou este app”, toque em Avançado → Acessar).
    5. Para cada texto novo: Arquivo → Fazer uma cópia do modelo. Cada cópia pede a autorização uma vez.

    No documento: a 1ª linha com estilo Título vira o título; Subtítulo vira o resumo; Título 1/2 e 3 viram intertítulos; parágrafo com recuo vira citação; um link do YouTube, Vimeo ou Spotify sozinho numa linha vira o player.
